This plugin allows displaying documents from a category in a Joomla article. To use this option:

1. Go to Extensions -> Plugins, find and enable the plugin **Content - DMS Category**
2. Edit the article which you want to display documents, enter this syntax {dmscategory ID_OF_CATEGORY} (replace ID_OF_CATEGORY with ID of the category which you want to display documents from)
