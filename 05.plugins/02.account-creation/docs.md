This plugin allows creating a Joomla! user account for the customer after they complete payment for the order. It is used when you have the two config options below set to **Yes**:

- **User Registration**
- **Only create user account for success orders**

To use this plugin, just go to Extensions -> Plugins, find and enable **Documents Seller - Account creation** plugin.
