Use these settings under **Documents Seller → Configuration** to control how categories and documents appear on your site.

## CSS framework and images

On **General**, set **CSS Framework** to match your Joomla site template. The available options are **Twitter Bootstrap 3**, **Twitter Bootstrap 4**, **Twitter Bootstrap 5**, and **UIKIT3**. Documents Seller uses Bootstrap 5 when no framework is set.

**Load Twitter Bootstrap** controls whether Documents Seller loads Joomla's Bootstrap stylesheet. Leave it at **No** if your template already loads Bootstrap or supplies UIkit. For a Bootstrap template that does not load the stylesheet, set it to **Yes**.

- **Resize Category Image** and **Resize Document Image** generate thumbnails when you save categories or documents with images. Set the corresponding thumbnail width and height in pixels.
- On **Themes**, enable **Show Default Category Thumbnail** or **Show Default Document Thumbnail** to display a fallback image in layouts that use thumbnails. These options apply when an item has no image of its own.

## Category and document listings

- On **Themes**, use **Categories Per Page** and **Documents Per Page** to set the default page sizes for listings. **Number Of Columns In Column Layout** controls how many documents appear per row in the columns layout.
- **Default Sort Option** and **Default Sort Direction** set the initial order of documents. Choose **Title**, **Date** (creation date), **Ordering**, or **Price**, and then **ASC** or **DESC**. Set **Show Sort Options** to **Yes** to let visitors change the sort order.
- **Show Document Detail In Popup** opens details links in a modal in supported layouts. **Show Download In Column** displays the per-document download allowance in supported tables, such as the category table and Orders History.
- On **General**, set **Show Documents From Children Categories** to **Yes** to include documents from subcategories in the parent category's document list.

See [Frontend Menu Options](/frontend-menu-options) for the available layouts.

## Sef Settings

These settings affect search-engine-friendly URLs generated by Documents Seller. If you change them on an existing site, check links you have already published or shared.

- **Insert Document ID** prefixes the document alias in the URL with its numeric ID. Use it if documents with duplicate aliases are difficult to distinguish in your URLs.
- **Insert Category** controls how much of the category path appears in the URL. Choose **All nested categories** to include the hierarchy or **Only the last one** to use just the final category. With **All nested categories**, **Insert Category ID** can prefix category aliases with their numeric IDs.

## Custom CSS

Use **Custom CSS** to add CSS rules for the Documents Seller frontend. Enable Joomla's **Editor - CodeMirror** plugin if the tab is missing. Saving the tab writes the rules to `media/com_dms/assets/css/custom.css`.
